# Native coverage: symbol records

This page is part of the [native coverage](../native-coverage.md) accounting. Read the [column and value definitions](../native-coverage.md#columns) first.
The kind lists come from `cvinfo.h` (`SYM_ENUM_e`), LLVM `CodeViewSymbols.def` and ms-codeview 0.1.7 `syms/kind.rs`.
The fixture counts are the module and shared records of the native fixture PDBs (see [fixture evidence](../native-coverage.md#fixture-evidence)).

`Symbol::decode` reads every record, and `SymbolData::encode` and `Symbol::encode` write it again to the same bytes.
`validate_module_symbols` and `validate_shared_symbols` check scope links, type, ID and module references and def-range gaps.
`ModuleSymbolWriter`, `SymbolRecordWriter`, `GlobalSymbolIndex::build` and `PublicSymbolIndex::build` rebuild the symbol streams and indexes. `PdbBuilder` (#33) and `PdbEditor` (#34) use them.
The layouts of the kinds above `0x1168` come from the debug type records of `cvinfo.h` in the DIA SDK `diaguids.lib` (#30).

## Symbol kinds

These are the modern kinds of `cvinfo.h`. `S_END`, `S_SKIP` and `S_OEM` have low values but belong to the modern format.
The `cvinfo.h` defines the DPC kinds (`0x1154` to `0x1158`) only if `CC_DP_CXX` is set.
